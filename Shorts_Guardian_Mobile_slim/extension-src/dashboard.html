About

Shorts Guardian v1.5.0
Text classification: keyword matching — fast, private, no API needed.
Image classification: Claude Haiku via Anthropic API (optional) or on-device MobileNet.
Audio: fully on-device with Whisper-tiny.

A weighted score (Visual 40% / Text 30% / Audio 30%) combines all three signals into a final Appropriate / Inappropriate verdict alongside an MTRCB-style rating (G / PG / SPG).

Flags are suggestions for your review, not automatic verdicts. Logs stay in your browser; only settings may sync, and only if you enable it.
